## Elections-Ad-Spending-Analysis ##
📌 Project Overview
This project analyses the advertising expenditure by political parties across Indian states and union territories during the 2024 General Elections, and investigates its correlation with voter turnout. The objective is to uncover patterns in campaign spending and how it might have influenced or coincided with public engagement (measured through polling percentages).

## Technologies Used
Python
Pandas – Data manipulation and analysis
NumPy – Numeric operations
Plotly – Interactive data visualisation
Jupyter Notebook – Data exploration and analysis
CSV Files – Source data format

Dataset Description
The analysis was based on three datasets:
1. advertisers.csv – Contains party names, page info, and total advertising spend.
2. locations.csv – Includes the amount spent by parties across Indian states and territories.
3. results.csv – Contains actual election results like voter turnout (Polled (%)) and state-wise info.
